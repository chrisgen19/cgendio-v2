# Fable 5.2 blog post Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a research-based, hands-on post about Claude Fable 5.2 for developers and dev clients, with my own screenshots and diagrams.

**Architecture:** Content only. One Markdown body in `prisma/seed-data/posts/`, one metadata entry in `posts.ts`, and four WebP images made in the scratchpad. Code examples are type-checked in a scratchpad project and never run. A scratchpad checker script enforces the copy rules on the Markdown. Production gets the post through the admin, because production only seeds an empty database.

**Tech Stack:** Markdown (react-markdown 10, remark-gfm, shiki 4.5), Prisma seed, Playwright MCP for screenshots, TypeScript 5 + `@anthropic-ai/sdk` 1.8.0 + `zod` 4.5.4 (scratchpad only), Next.js 16.4.2 conventions.

**Spec:** `docs/superpowers/specs/2026-11-12-fable-5-2-post-design.md`

## Global Constraints

- **No Claude API calls on any model** ("just do research, not from our own tokens"). Never run the code examples.
- Every stat, quote and API detail must link to a source checked during Task 1. Figures read "as of November 12, 2026".
- Write in the first person "I", never "we", "us" or "our" (code comments included). No em dashes or en dashes.
- No claims of client results: "how I'd use it", not "how I used it".
- Never describe WordPress as slow or outdated.
- Sources are Hacker News and X plus Anthropic's own material. No Reddit. The post says so in one sentence.
- No Anthropic press images, logos or brand art. Screenshots are of public pages, cropped by me.
- Use only these exact model IDs: `claude-fable-5-2`, `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`.
- No new packages in the project. The scratchpad project may install `@anthropic-ai/sdk@1.8.0`, `zod@4.5.4`, `typescript@5` and `@types/node`.
- Slug `claude-fable-5-2-developer-guide`, tag `AI workflow`, status `DRAFT` in the seed.
- Uploads: jpg, png, webp or avif only (`src/server/r2.ts:8`).
- Any production change (an R2 upload through the production admin, creating or publishing the post) waits for Christian's go-ahead.
- Commits use Conventional Commits on `feature/fable-5-2-post`, and only when Christian asks.

`$SCRATCH` below means `/private/tmp/claude-501/-Users-chrisgen19-projects-cgendio-v2/f5b9e1fb-c520-4cca-8677-9e8dd3bb8938/scratchpad/fable-post`.

## Review Focus

1. **Dark mode:** a diagram or screenshot with a transparent background disappears on the dark theme. Every image needs a solid white background and a 1px `#E3E5EA` border inside the file. The Task 3 check covers this.
2. **Quotes:** a misquoted or misattributed HN or X comment is the most damaging error. Each quote must appear verbatim on its page. Task 1 checks this, and Task 4's checker rejects any quote that isn't in the notes.
3. **Code copied by readers:** an example that doesn't compile against the current SDK (wrong beta name, wrong `fallbacks` shape, forced `tool_choice`) defeats the post. `tsc --noEmit` in Task 2 covers this, plus a grep that fails on `tool_choice: {type: 'any'` / `'tool'`, `budget_tokens` and `thinking: {type: 'disabled'`.
4. **Phone width (390px):** the benchmark table and long code lines. The prose already scrolls both (`markdown.tsx:77`, `:115`). Keep the table to four columns and check it in Task 4.
5. **Stale numbers:** HN points and comment counts keep changing. Write them as "at the time of writing (November 12, 2026)". Task 4's checker requires that phrase to appear if the post mentions any points.
